# Chat Room

A starter direct-messaging app with PostgreSQL persistence, Socket.IO chat and in-app notifications, PostgreSQL-backed scheduled delivery, Redis/BullMQ message expiry, and a React/Vite client.

## Requirements

- Node.js 20.19+ and npm
- PostgreSQL
- Redis

## Setup

1. Create a PostgreSQL database named `chat_app`, then run `schema.sql` against it.
2. Update `backend/.env` with your local PostgreSQL connection string and a long random `JWT_SECRET`. The checked-in values are placeholders.
3. Install and start the backend:

   ```powershell
   cd backend
   npm install
   npm run dev
   ```

The backend adds the message read-receipt, scheduling, and expiry columns and the scheduled-message index to existing databases at startup. Scheduled messages are stored in PostgreSQL and delivered by the backend, so Redis is not needed for scheduled sending. Redis is used for message expiry. Sent messages show an eye to the sender after the recipient opens that conversation.

4. In another terminal, install and start the frontend:

   ```powershell
   cd frontend
   npm install
   npm run dev
   ```

5. Open the Vite URL (normally `http://localhost:5173`). Configure `VITE_TRANSLATE_API_URL` in `frontend/.env` to enable translation using a LibreTranslate-compatible endpoint. The app does not bundle a translation service.

The backend expects Redis at `redis://localhost:6379` by default. Change `REDIS_URL` in `backend/.env` as needed. Friend codes and auth tokens are generated by the backend; do not expose environment files or production secrets.

The notification bell shows incoming friend requests, accepted requests, and new messages while the user is connected. Pending friend requests are loaded when the user signs in; other notifications are kept in app memory until reload and are not stored as notification history.
